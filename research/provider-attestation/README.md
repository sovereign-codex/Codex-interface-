# Real Provider Attestation Research

This directory captures the 2026-11-08 review of provider identity surfaces relevant to TYME Hall.

The central finding is that provider identity has multiple scopes and directions. Account credentials, workload identity, transport client identity, agent identity, app-installation identity, model identity, and session identity MUST remain distinct.

The machine-readable matrix is `provider-capability-matrix-v0.1.json`.

Primary official sources are listed inside each provider record.
