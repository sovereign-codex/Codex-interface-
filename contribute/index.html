Contribution

Participation begins with inspectability, not agreement or authority.

How can I enter responsibly?

A useful contribution starts from something publicly inspectable: a contradiction, stale state, broken link, ambiguous definition, unsupported relationship, reproducibility problem, accessibility failure, privacy concern, or bounded implementation opportunity.

Contribution does not grant institutional authority. A returned finding may be reviewed, corrected, declined, superseded or integrated through the existing human and repository gates.

Useful contributions

  • Find contradictions, broken links and unclear definitions.
  • Improve documentation and accessibility.
  • Reproduce or challenge technical and scientific claims.
  • Submit code with narrow scope and explicit assumptions.
  • Identify where a hypothesis is being presented too strongly.
  • Help connect records to primary sources and provenance.

Return a bounded finding

For the current public Hall, use the Codex-interface repository as the concrete return path. Preserve four things:

  1. Observation — what you actually encountered.
  2. Evidence — the public page, record, source or reproduction that supports it.
  3. Interpretation — what you think the evidence means, clearly separated from observation.
  4. Proposed correction — the smallest change that would repair the demonstrated problem, if a correction is warranted.

Review discipline

Preserve uncertainty when the public evidence does not resolve a claim. Report contradictions and inaccessible evidence rather than silently filling gaps by assumption.

Contribution rule

Prefer a traceable correction over persuasive certainty. Separate observation from interpretation, implementation from aspiration, and participation from authority.
